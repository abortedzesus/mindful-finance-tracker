# 🧾 Kakeibo – Mindful Finance Tracker

A full-stack expense tracking web app inspired by the Japanese **Kakeibo** method – helping users track spending, savings, and financial habits more mindfully.

## 🚀 Features
- 🔐 Authentication (Email / Phone login)
- 💸 Expense tracking
- 📊 Dashboard with insights
- 🧾 Bills management
- 🎯 Savings goals tracking
- 👤 User profile system

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** FastAPI
- **Database:** MySQL
- **Auth:** JWT-based authentication


## ⚙️ Setup

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn run:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## 💡 Inspiration
Based on the Japanese budgeting method **Kakeibo (家計簿)** — focused on mindful spending.
